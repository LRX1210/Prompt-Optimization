本项目聚焦大模型提示词优化，围绕指令规范、角色设定、示例引导、边界约束等方向开展实验。通过对比不同提示词方案的输出效果，筛选高效的提示构造范式，减少模型幻觉，提升回答准确性、逻辑性，适配学术问答、智能体等场景，为AI应用落地提供轻量化优化方案。
This project focuses on LLM prompt optimization. 
It conducts experiments on instruction standardization, role setting, few-shot guidance and boundary constraints. By comparing outputs of different prompts, 
it selects efficient prompt templates to reduce hallucinations and boost accuracy and logic. 
Suitable for academic Q&A and agents, it provides a lightweight optimization scheme for AI deployment.
